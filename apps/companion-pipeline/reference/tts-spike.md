# TTS listen-test spike (plan phase tts_spike)

Voice selection record for ar / ur / id. Samples are generated by
`companion spike-tts` into `out/spike/` (gitignored — regenerate any time;
cached by text+voice). One shared sample text per language (an intro-style
line), one wav per candidate voice, all through the production TTS path
(`tts.gemini_generate`, model `gemini-3.1-flash-tts-preview`).

## Spike run, 2026-07-28

All 12 samples (3 languages × 4 voices) generated successfully — no API
errors for any language. **Urdu produced audio** (the documented Gemini
TTS language list omits Urdu, so this was the flight risk): durations
12.1–13.5s, consistent with the sample length. Whether the Urdu accent,
pronunciation, and register are acceptable is a HUMAN call — samples sent
to the architect for the listen test.

`languages/<lang>/config.toml` and this table is updated with who decided
and when. On rejection of all Gemini candidates for a language: the spec's
§Assumptions decision rule applies (fallback chain, then architect scope
escalation); the escalation gets recorded here.
